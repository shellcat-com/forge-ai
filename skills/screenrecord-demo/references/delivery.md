# Deliver and save drafts

## Files and documentation

Use an MP4 with H.264, yuv420p, fast-start metadata, and optional stereo AAC as a broadly compatible starting point. Verify destination-specific limits from current official documentation when needed. Do not invent platform requirements or promise impressions.

Deliver an absolute local file link and actual duration. A localhost preview URL is not a public deployment. Preserve the timeline and raw footage for revisions. State whether visual inspection and listening were completed, and report any material limitation plainly.

When a repository update is requested, follow its instructions. Copy only the final shareable video and poster into the intended documentation location, verify the copy, and add a concise README reference. Preserve unrelated edits. Do not imply a local edit has been committed, pushed, or published.

## Social drafts

1. Confirm the active profile using current visible identity and profile context; a matching display name alone can be ambiguous.
2. Inspect an existing draft before editing. Preserve text or attachments the user wants to keep. Emphasize what the user built and what the recording actually demonstrates; avoid unsupported production claims or fabricated metrics.
3. If video attachment is requested, upload the actual local video through the available documented upload control. Pasting its local path or URL into the text is not an attachment.
4. Wait for processing to finish and verify the preview or video player. Use the platform's draft-save flow, then reopen once to confirm that **both text and video** persisted.
5. Leave the result as a draft when requested. Do not click Post, Publish, or Schedule as a workaround for draft limitations.

Native file pickers may appear late or change focus. Refresh the UI state and identify the correct sheet before entering a path. Avoid repeated blind clicks or accidentally pasting a path into the address bar. Use the current tool's documented file-upload or native-dialog methods.

If the platform cannot retain video in an unpublished draft, preserve the local video and post text, explain the verified limitation, and leave the safest reviewable state. Do not claim a saved attachment without checking it.

Social copy research is optional unless requested. When requested, browse current sources and apply relevant advice with judgment; keep the user's voice and factual claims. Links, hashtags, captions, and voiceover follow the user's preferences rather than a universal template.
