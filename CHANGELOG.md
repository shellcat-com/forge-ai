# Changelog

## 0.2.0 — Unified local builder checkpoint

- Combined the approved Forge interface and Next.js engine, with optional Examples and canonical routes.
- Added prompt-first creation, persistent modes/design briefs, project search, mobile workbench views, editor recovery and review permissions.
- Expanded file generation with nested routes/components, bounded build repair and durable cancellation checks.
- Added Better Auth/Drizzle foundations and additive local project imports while preserving original histories.
- Hosted previews, cloud replacement, visual editing and publishing remain incomplete. See the implementation status for tests and release blockers.

All notable changes to this project will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project intends to follow [Semantic Versioning](https://semver.org/) once a supported runtime exists.
