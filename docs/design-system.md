# Forge interface system

Charcoal backgrounds (#0c0e0d), warm white text (#f0f0e8), lime accents (#d7ff46), muted green-gray supporting text. Manrope handles interface typography; DM Mono handles metadata. Font files are bundled locally through Fontsource. Spacing uses a 4px base with 12px panels, 6–9px controls, subtle borders, and restrained shadows. Focus rings are visible lime outlines. Hover transitions last 160ms and are disabled for reduced motion.

At 700px the side navigation becomes a header; prompt controls remain available. Cards stack on mobile. Tested target widths are 375, 768, and 1440px.

## Reference study and selected patterns
- OpenCode (https://opencode.ai): technical typography and explicit local/provider boundaries, useful for honest readiness communication.
- Spectrum UI (https://ui.spectrumhq.in): compact prompt controls and stateful interaction, useful for the composer and starter selection.
- Cursor Bugbot (https://cursor.com/bugbot): embedded workflow demonstrations and concise review status, reserved for the real generation timeline and diffs.
- Hermes (https://hermes-agent.nousresearch.com): bold accent and open-source positioning, expressed through Forge's existing lime identity rather than copied art.
- Linear (https://linear.app): dense navigation and disciplined hierarchy, used for the personal workspace frame.
- Raycast (https://raycast.com): keyboard-first operation, visible focus and short response transitions.

Mobbin was unavailable. No full screen, trademark, illustration, or copy was duplicated. Before-and-after and evidence guidance is adapted for local artifacts only; no third-party uploads. The upstream tests directory contains recorder tests rather than a standalone tests skill.
