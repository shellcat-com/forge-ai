# Forge interface and optional examples

[DESIGN.md](../DESIGN.md) is authoritative. Forge uses self-hosted IBM Plex Mono, semantic neutral tokens, thin borders, paired light/dark themes, original landscape artwork and restrained motion. The engine's former lime/Manrope interface has been retired.

Home places a prompt composer above recent projects. Build is the default; Idea, Brainstorm and Plan share the same context. Visual direction and the five examples are optional. Generated applications own their fonts, colors and layouts inside isolated previews.

Global navigation expands on desktop Home and Projects and collapses in the builder. Narrow layouts start with the drawer closed. The builder provides Chat, Preview and Tools views on narrow screens, and conversation beside preview on desktop. Code, History and Review retain the project's context. Panel, file and viewport preferences are stored per project.

Current captures live in `docs/evidence/unified`. They show the actual integrated application; inherited evidence elsewhere is historical. See the implementation report for checks and limitations. The competitor archive remains private and its video is a reconstructed screenshot walkthrough.
