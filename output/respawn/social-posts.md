# LinkedIn draft

From a product brief to a working gaming storefront.

I connected a server-side DeepSeek provider to Forge, generated a standalone marketplace frontend, and gave it a visual identity with original GPT artwork.

The result is Respawn: search, category filters, saved products, cart controls, a demo checkout, and light/dark layouts across mobile and desktop.

The most useful part was the review. Generated code still needed fixes: cart event handlers, modal focus, visible icons, and clearer demo boundaries. That work is part of the process.

This three-minute walkthrough shows the actual Forge request and the finished frontend. Generation waiting time is edited out. Login and checkout are demos; real services are a separate next step.
